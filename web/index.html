FLIGHT RULES
pilot
a model of a fly's brain, MaleCNS: 166,700 neurons, 25.6 million synapses. It sees only the window frame — the picture its 3,335 photoreceptors receive.
lever
right DNp20 neuron minus left. On the way out the lever turns the rocket; in the landing it moves the rocket sideways. Nothing else steers.
computer
throttle, the flip engines-first, braking, descent rate, and near the ground a limit on sideways speed. It never knows where the target or the pad is.
world
the same rules for every flight of a level. The mission number only picks where the rocks, the meteors and the pad are.
touchdown
sensors on the legs drive 2,522 leg mechanosensory neurons of the fly; the brain's answer goes into the log.
control
the same brain with the window painted over. The blind fly never lands — so it is vision that steers.
check
every flight is deterministic: the same level and number give the same flight to anyone who runs the code.
